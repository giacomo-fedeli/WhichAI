**Short description (20-30 words):**
A website that ranks AI models by an independent benchmark score, compares any two side by side and shows current API prices. No account is needed to use it.

**Long description (50-500 words):**
WhichAI is a single web page for people who need to choose between AI models. It lists current models sorted into tiers according to the Artificial Analysis Intelligence Index, a public benchmark, and places each one on a chart of price against score. Two models can be compared head to head, including price, context size and strengths. A market section shows what each tier costs, which models are free at the moment and the estimated monthly cost for a given amount of use. A news section collects headlines from AI labs and the technology press. Another section sets out the main public debates about AI, such as energy use, jobs and copyright, with the arguments from both sides. The tools section helps pick a model for a task and write a prompt for it. The site does not run its own benchmarks. Scores and prices are read automatically from public sources, and each figure is labelled with its origin. Nothing needs to be installed, there is no sign-up and no advertising. Preferences stay in the browser. The interface is available in 11 languages, the site can be installed as an app, and the data set is published as open data under a CC BY 4.0 licence.

**How is this tool unique or different?** (non elencare funzioni)
Most AI leaderboards answer one question: which model scores highest. Choosing a model also depends on what it costs and what the job is, and those numbers usually sit on other sites. WhichAI puts score, price and task in one place and updates them without anyone editing a table by hand. It credits the original publishers of every number instead of presenting them as its own measurements, and it links to them. It has no ads, no accounts and no affiliate rankings, so the order of the list is not for sale. It is a small independent project built by one person, not a company product.
