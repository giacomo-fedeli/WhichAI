# Security policy

WhichAI is a static site with a small read-only API. It has no accounts, no database and no user data on the server: what you type stays in your browser.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting ("Report a vulnerability" under the Security tab of this repository), or contact Giacomo Fedeli through [LinkedIn](https://www.linkedin.com/in/giacomo-fedeli-277765239/).

Useful details: the page or endpoint, the steps to reproduce, and the browser. You will get a reply as soon as possible; this is a one-person project, so please allow a few days.

## Scope

In scope: https://whichai.wiki, the `/api/*` endpoints and the code in this repository. Out of scope: third-party services the site links to, and findings that need a compromised device or browser.

## Supported versions

Only the live version at https://whichai.wiki (see the footer for the number) is supported.
